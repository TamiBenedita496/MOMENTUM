MOMENTUM — FASE 1 (PROTÓTIPO)

Abrir index.html no computador permite testar a interface e salvar dados localmente.
Para instalar no Android como PWA, hospede TODOS os arquivos desta pasta juntos em um site HTTPS (ex.: GitHub Pages). No Chrome Android, abra o site e use o menu > Instalar app / Adicionar à tela inicial.

Funciona agora: tarefas básicas, filtros, eventos, sessões de foco com registro parcial, hábitos semanais, modo escuro, backup JSON.
Não funciona ainda: sincronização entre dispositivos, login, notificações push, subtarefas, comentários, Kanban, gráficos avançados e temporizador persistente após recarregar/fechar a página.

IMPORTANTE: os dados ficam apenas no armazenamento local do navegador e podem ser perdidos ao limpar dados do site. Exporte backups regularmente. Para instalar via HTTPS, publique em um host HTTPS. O protótipo não solicita permissão de notificações.
